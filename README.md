## 写真

ふくし体験プログラム5本（車いす体験・白杖体験・高齢者疑似体験講座・災害ボランティアセンター運営体験・認知症サポーター養成講座）・ボランティア入門講座と防災ビンゴゲームの写真は、資料に埋め込み済みです（HTMLに直接埋め込んでいるので、この1ファイルを渡すだけで写真も表示されます）。

残る3つ（避難所体験・助けられ上手・助け上手・サバメシ作り）には写真スロット（点線の枠）が入っています。写真ができたら、HTML内の

```html
<div class="photo">
  ...
</div>
```

をまるごと次のように置き換えてください。

```html
<img class="photo" src="photos/bousai-bingo.jpg" alt="ビンゴで盛り上がるようす">
<p class="photo-cap">防災ビンゴゲーム：わが家に足りないものを書き出す</p>
```

写真は `photos` フォルダに入れてください。ただし、この方法だとHTMLと写真をセットで渡す必要があります。1ファイルで完結させたい場合は、埋め込み済みの3枚と同じようにデータとして直接埋め込みます（依頼してください）。

## 印刷するとき

ブラウザの印刷機能（Ctrl+P / ⌘+P）で、そのまま **A3・縦** で刷れます（用紙サイズはHTML側で指定済み）。

- 印刷設定で「背景のグラフィック」にチェックを入れてください（色分けが出ます）
- 全9ページです
- A4で刷りたいときは、印刷設定の用紙サイズをA4に変えて「用紙に合わせる」を選んでください
